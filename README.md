# Jules Baji

Site personnel : présentation, parcours et résultats de stage au CEA Saclay (Gaussian Splatting).

- `images/` et `videos/` : fichiers d'origine, conservés.
- `images/web/` et `videos/web/` : versions allégées affichées sur le site.
- `rapport/` : rapport de stage CEA (PDF allégé, images recompressées).
- `cv/` : CV en PDF.
- `en/` : version anglaise du site.
- `stage-cea.html`, `en/cea-internship.html` : page détaillée du stage au CEA.
- `assets/` : styles et scripts communs ; `tools/build_site.py` génère les pages FR et EN à partir des mêmes textes.
